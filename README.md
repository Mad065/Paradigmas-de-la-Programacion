# Paradigmas de la Programación

¡Bienvenido a mi repositorio de la materia **Paradigmas de la Programación**!

Este repositorio está dedicado a almacenar apuntes y las prácticas en código. Aquí exploro las diferentes formas de pensar, estructurar y resolver problemas a través de los distintos paradigmas de programación (imperativo, declarativo, funcional, orientado a objetos, etc.).

---

## 🛠️ Tecnologías y Lenguajes

Principalmente utilizaremos los siguientes lenguajes durante el curso:

* **Paradigma Imperativo / POO:** `C`, `C++`, `Java`
* **Paradigma Funcional:** `Haskell`, `Lisp`
* **Paradigma Lógico / Consulta:** `Prolog`, `SQL`
* **Otros / Multiparadigma:** `Python`

---

## 📁 Estructura del Repositorio

El contenido está organizado de forma sencilla en las siguientes carpetas:

* [`/apuntes`](./apuntes): Notas de clase, tablas comparativas y resúmenes teóricos en formato Markdown (`.md`).
* [`/practicas`](./practicas): Ejercicios en código y programas de laboratorio clasificados por paradigma o tema.
